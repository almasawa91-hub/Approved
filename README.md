# محاسب سوفت — إعادة بناء Android

هذا المستودع يعيد بناء واجهات ووظائف مختارة كتطبيق Android أصلي باستخدام Kotlin وJetpack Compose، بالاستناد إلى ملفات التحليل المتاحة في [almahaseb-pro-apk-analysis](https://github.com/almasawa91-hub/almahaseb-pro-apk-analysis).

## ما يعمل في النسخة الحالية
- واجهة عربية RTL مع أقسام رئيسية وشريط تنقّل.
- قاعدة SQLite محلية تبدأ فارغة، مع ترحيل يحافظ على سجلات النسخ التجريبية السابقة.
- إضافة الحسابات وتعديلها وتعطيلها دون حذف السجل، مع تصنيفات منفصلة للعملاء والموردين والأصول والصناديق والبنوك والمصروفات والإيرادات ورأس المال وغيرها.
- إضافة الأصناف وتعديلها وتعطيلها، مع التصنيف والوحدة والكمية وسعر البيع والتكلفة.
- بحث مباشر بالبادئة عن الحسابات والأصناف، واقتراح الأصناف أثناء إنشاء الفاتورة.
- حفظ مسودات فواتير البيع والشراء متعددة البنود، مع حساب الإجمالي باستخدام BigDecimal.
- شاشة إحصاءات تعرض أعداد السجلات المحلية الفعلية.
- GitHub Actions يبني APK Debug ويتحقق من سلامة أرشيف APK ثم يرفعه كـ Artifact.

## قيود يجب معرفتها
- ملفات المرجع المفككة ليست مشروع Gradle جاهزًا، ولا تتضمن ملفات Smali المطلوبة لإعادة تجميع APK الأصلي مباشرة.
- الفواتير تُحفظ كمسودات فقط؛ لا تُرحّل قيودًا محاسبية ولا تغيّر المخزون.
- لم تكتمل بعد بقية شاشات التطبيق الأصلي، مثل الترحيل المحاسبي المتوازن والتقارير المالية والطباعة وPDF والنسخ الاحتياطي والمزامنة.
- لم تُختبر بعد على جهاز Android فعلي؛ نجاح GitHub Actions يثبت نجاح البناء والتحقق من ملف APK، وليس اختبارًا ميدانيًا للتطبيق.

## تنزيل النسخة
افتح [GitHub Actions](https://github.com/almasawa91-hub/Approved/actions)، ثم افتح أحدث تشغيل ناجح ونزّل approved-debug-apk من قسم Artifacts.
