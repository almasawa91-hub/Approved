# محاسب سوفت — إعادة بناء Android

هذا المستودع يعيد بناء واجهات ووظائف مختارة كتطبيق Android أصلي باستخدام Kotlin وJetpack Compose، بالاستناد إلى ملفات التحليل المتاحة في [almahaseb-pro-apk-analysis](https://github.com/almasawa91-hub/almahaseb-pro-apk-analysis).

## ما يعمل في النسخة الحالية
- واجهة عربية RTL مع أقسام رئيسية وشريط تنقّل.
- قاعدة SQLite محلية تبدأ فارغة، مع ترحيل يحافظ على سجلات النسخ التجريبية السابقة.
- إضافة الحسابات وفصلها إلى تصنيفات: العملاء، الموردون، الأصول، الصناديق، البنوك، المصروفات، الإيرادات، رأس المال، وأخرى.
- إضافة الأصناف والبحث بالاسم أو الرمز أثناء الكتابة، مع التصنيف والوحدة والكمية وسعر البيع والتكلفة.
- إنشاء مسودات فواتير البيع والشراء متعددة البنود، مع اقتراح الأصناف أثناء الكتابة وحساب الإجمالي باستخدام أرقام عشرية دقيقة.
- GitHub Actions يبني APK Debug ويتحقق من وجود الملف ثم يرفعه كـ Artifact.

## قيود يجب معرفتها
- ملفات المرجع المفككة ليست مشروع Gradle جاهزًا، ولا تتضمن ملفات Smali المطلوبة لإعادة تجميع APK الأصلي مباشرة.
- الفواتير تُحفظ كمسودات فقط في هذه المرحلة؛ لا تُرحّل قيودًا محاسبية ولا تغيّر المخزون.
- لا تُعد هذه النسخة استعادة كاملة بعد لكل الشاشات والتقارير والطباعة والنسخ الاحتياطي والمزامنة في التطبيق الأصلي.
- لم تُختبر بعد على جهاز Android فعلي؛ نجاح GitHub Actions يثبت نجاح البناء والتحقق من وجود APK فقط.

## تنزيل النسخة
افتح [GitHub Actions](https://github.com/almasawa91-hub/Approved/actions)، ثم افتح أحدث تشغيل ناجح ونزّل approved-debug-apk من قسم Artifacts.
